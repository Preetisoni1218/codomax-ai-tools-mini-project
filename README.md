# AI Study Assistant

## Project Overview

AI Study Assistant is a simple Python-based project designed to help students study different topics.

The project accepts a study topic from the user and provides a simple explanation, key points, summary, and practice questions.

## Features

* Accepts a study topic from the user
* Provides a simple explanation
* Provides important key points
* Generates a short summary
* Provides practice questions
* Simple and beginner-friendly Python program

## AI Tools Explored

During this module, I explored:

* ChatGPT

* Microsoft Copilot

These tools can assist with coding, research, brainstorming, learning, and productivity.

## Technologies Used

* Python
* GitHub

## How It Works

1. The user enters a study topic.
2. The program processes the topic.
3. The program displays study material.
4. The user can use the generated content for revision and practice.
